## 研究主线

当前个人材料体系为 **Bi₂Te₃（碲化铋）**，主线为 SPS 制备母材、阵列成形、三维互连多孔结构与器件应用。磁控溅射仅用于模板前驱膜；SPS 制块与模板压入是两项不同工艺。旧 Sb–Te / Sb₂Te₃ 资料保留原材料标签，不能改写成个人 Bi₂Te₃ 实验结果。

文献中的 500 MPa 等工艺参数是特定样品的报道条件，不构成已证实的最低压力或本项目操作配方；涉及 S、σ、κ、PF、ZT 的数值须回到原文和补充材料核对。
