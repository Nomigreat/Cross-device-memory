# Project-0029 热电 ZT 数据数字化

## 需求

用户提供 Sb₂Te₃ / Bi₂Te₃ 热电性能五联图截图，要求：
1. 解释各子图与符号含义（含符号关系）；
2. 将其中的 zT 值整理成表格，含数据项/参数名称、zT 值与表头说明，数值准确、排列清晰。

## 输入材料

- `02-输入材料/图_e_zT温度依赖_原始截图.png` —— 原始五联图截图（含 (a)~(e) 五个子图）。

## 方法

图像数字化（非作者原始数据）：

1. 在截图上定位子图 (e) 的坐标框与刻度线（左轴 x=811 px，右轴 x=1105 px 为 (c) 图；子图 (e) 框为
   x=645→952 px、y=315→563 px），建立像素 ↔ 数据映射：
   - 横轴：x=673 px → 300 K，x=952 px → 550 K（1 K ≈ 1.116 px，经 6 个刻度标签中心验证）
   - 纵轴：y=315 px → zT=1.2，y=562.5 px → zT=0.2（0.1 zT ≈ 24.75 px）
2. 按 HSV 色相 + 明度对像素分类，区分 6 条数据序列（黑 / 红 / 蓝 / 青 / 品红 / 暗红），
   排除图例框与 (e) 角标区域。
3. 在每个温度点的 ±5 px 窗口内取该颜色像素的中位数作为标记中心，换算为 (T, zT)。
4. 对重叠严重的点（首个温度点、473 K、520 K）逐列打印像素 RGB 人工复核。
5. 叠加 0.05 网格线放大 4 倍回看，交叉验证读数。

## 交付物

- `05-交付物/zT数据表_Sb2Te3-Bi2Te3.xlsx` —— 6 组样品 × 6 个温度点的 zT 数据表，
  含材料体系 / 制备条件 / 图例符号列、峰值 zT 与峰值温度列，以及表头说明与读数说明。

## 关键结论

| 样品 | 峰值 zT | 峰值温度 |
|---|---|---|
| Bi₂Te₃ SPS-5 min | ≈0.83 | ≈426 K |
| Bi₂Te₃ SPS-10 min | ≈0.80 | ≈426 K |
| Sb₂Te₃ SPS-5 min | ≈0.90 | ≥520 K（未达峰） |
| Sb₂Te₃ SPS-10 min | ≈0.87 | ≥520 K（未达峰） |
| Ref.[18] | ≈0.69 | ≈520 K |
| Ref.[19] | ≈0.47 | ≈426 K |

- 四组自制样品在 400 K 以上均高于两支文献参考值。
- Bi₂Te₃ 体系在 426 K 附近达峰后回落；Sb₂Te₃ 体系在整个测量区间持续上升。

## 边界与风险

- 数据由图片读数得到，zT 不确定度约 ±0.02，温度点约 ±3 K；正式引用须以原文数据为准。
- 测量温度点由图上刻度数字化得到（约 314 / 333 / 377 / 426 / 473 / 520 K），
  与文献常见的标称点（如 313 / 333 / 373 / 423 / 473 / 523 K）可能存在小幅出入。
- 颜色与样品的对应关系取自图例顺序（■ Sb₂Te₃-5、● Sb₂Te₃-10、▲ Bi₂Te₃-5、▼ Bi₂Te₃-10）。
