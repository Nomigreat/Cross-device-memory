# 长文档的高效质量检查 · 方法003
适用修订：旧有全文读取治理文件的前置条件，按2026-09-21用户要求改为定向检索、按需读取。调用次数仅历史参考，不能替代质量验收。

- 适用场景：基于 PDF、教材、论文或既有总结生成长篇 Word/PDF 等文档交付物。
- 不适用场景：OCR、复杂公式、关键证据冲突或特殊排版异常尚未解决时，不得套用调用次数参考强行收尾。
- 标准步骤：复用已有来源提取与成果 → 只加载当前任务必要上下文 → 结构预检 → 集中生成 → 结构 QA → 仅复查变更页及边界页 → 最终全篇视觉 QA → 实际文件验证。
- 成功判据：内容覆盖、证据边界和最终 QA 不降低；重复读取与重复渲染显著减少；约 20–30 页且来源提取可靠、模板明确的 Word 任务，通常控制在约 15–25 次模型续调用。
- 常见失败模式：在超长对话中高频碎片化调用；结构未稳定即反复全篇渲染；重复查看未变化页面；为省 Token 取消关键核验。
- 核心原则：少做重复劳动，不少做关键工作。
- 证据来源项目：Project-0008-材料概论教材全面总结。
- 最后验证日期：2026-08-31。
