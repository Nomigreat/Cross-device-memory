# 半导体强韧化与柔性热电文献 · 指标与证据边界

## 力学量不能互换

| 报告量 | 实际表示 | 不能直接推出 |
|---|---|---|
| 压缩屈服/最大应力 | 特定几何、方向、温度、速率下的压缩承载 | 拉伸强度或断裂韧性 |
| 纳米压痕硬度H | 局部压入硬度；有时作者以H/3估计强度 | 直接拉伸强度；H/3需标为模型估算 |
| 总标距伸长 | 含均匀段、颈缩和断裂后的总位移 | 均匀延性；S07的75.7%在此类别 |
| 压缩工程应变 | 试样轴向缩短量/初始长度 | 拉伸塑性、抗疲劳 |
| 开裂起始应变εcr | 特定薄膜/基底组合首次观察裂纹或阻值拐点 | KIC、J积分或本征断裂能 |
| 弯曲半径/循环数/ΔR | 柔性器件结构测试及循环稳定性代理 | 薄膜的本征拉伸韧性 |
| 器件整体应变 | 包括骨架/基底/几何构型的应变 | 半导体薄层本征应变 |

跨论文引用前必须记录：试样尺度、取向、载荷方式、温度、应变速率、屈服定义、重复数、误差、基底和厚度。

## 热电指标量纲

- PF=S²σ；单位换算：μW cm⁻¹ K⁻² ×100 = μW m⁻¹ K⁻²。
- ZT=PF·T/κ；需要同一成分/试样/温度下的PF和总热导κ。
- κL是晶格热导，不等于总κ。
- 只报告PF或电压不能替代ZT或可用输出功率；器件输出须有I–V、负载、温差、面积定义和测量电路。

## 韧性与“柔性”用词

“高韧性”若依据弯折、不开裂或ΔR小，应写为对应弯折/循环表现；没有断裂能/KIC/J积分时，不升级为材料断裂韧度。专利题名和权利要求用词不是独立测量结果。

## 引用前最小证据句式

“在[材料与结构]、[试样尺度/取向]、[载荷与温度/速率]下，报告[具体指标和定义]为[数值]；证据见[PDF页/图/表]。该结果不直接代表[不可外推范围]。”
