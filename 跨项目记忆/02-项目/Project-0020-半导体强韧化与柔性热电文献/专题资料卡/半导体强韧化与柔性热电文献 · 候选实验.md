# 半导体强韧化与柔性热电文献 · 候选实验

以下是基于本批资料形成的候选假设，不代表已查新、可行性已证实或导师已确认。

## 1. CdTe：固定微柱几何，改变初始缺陷密度
- 假设：在同一柱径下，控制层错/孪晶密度会改变位错储存、加工硬化与局部应变分布。
- 增量：S06的尺寸序列改为“柱径固定×缺陷密度”设计。
- 验证：同批FIB制样；盲法测压缩曲线、局部应变、TEM缺陷；至少3级缺陷密度并重复。
- 失败风险：难以独立调缺陷；FIB损伤差异掩盖效应。
- 来源：S06 PDF p.3–7；创新状态未核查。

## 2. Bi₂Te₃：固定厚度调层错密度
- 假设：层错密度变化对εcr和电输运有独立贡献。
- 增量：控制膜厚、晶粒、粗糙度和PI基底，只改变边界/层错结构。
- 验证：微拉伸/裂纹起始、循环弯折ΔR、Hall/PF配对测量。
- 失败风险：热处理会同时改变晶粒/成分；基底应变无法精确分离。
- 来源：S08 PDF p.3–8；创新状态未核查。

## 3. Ag₂Te：畴界效应与热历史解耦
- 假设：固定热历史、化学计量和析出后，改变畴宽仍会影响压缩与κL。
- 增量：加入热历史匹配对照，并逐样品关联TEM、力学、Hall及热输运。
- 验证：同批样品配对；多畴宽水平；报告样品级而非跨条件最优值。
- 失败风险：退火同时消除位错/改变Ag迁移；畴宽不可独立控制。
- 来源：S09 PDF p.2–7；创新状态未核查。

## 4. SnTe：固定成分改变析出尺度
- 假设：在固定Mn含量下调控析出尺寸/体积分数可改变强度—断裂应变Pareto关系。
- 增量：从成分扫描转为析出演化系列，核对模型项和实际总强化。
- 验证：TEM定量析出/位错/晶粒，同试样压缩和TE；复算单位与误差传播。
- 失败风险：基体Mn浓度随析出变化；热处理导致晶粒长大/位错回复。
- 来源：S13 PDF p.3–8；创新状态未核查。

## 5. 柔性热电器件：弯折与环境耦合可靠性
- 假设：弯折与热/氧化循环并用会加速ΔR和输出衰减，且超出单因素效果。
- 增量：从材料片短期弯折扩至器件级因子设计。
- 验证：空白、单因素和组合组；统一半径、温差、负载；预设失效阈值并记录形貌。
- 失败风险：器件批次差异大；环境过程与接触电阻失效混杂。
- 来源：S12 PDF p.14；创新状态未核查。

## 通用最小对照

优先把一个结构变量设为主变量，匹配基底/厚度/热预算/成分；同一样品或明确配对样品同时测力学与TE；报告n、误差、加载定义和失效模式。开始前做针对性查新，并与导师确认设备可行性。
