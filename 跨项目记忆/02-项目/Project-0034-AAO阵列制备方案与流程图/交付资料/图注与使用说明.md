# Sb₂Te₃–AAO 表面阵列制备流程

本图用于组会介绍拟定路线。阅读顺序为上排从左向右，右端向下，下排从右向左，共八步：球磨、SPS制备块体、表面整平、AAO贴合装样、热机械压入、去除AAO、清洗干燥、阵列表征。

蓝色代表Sb₂Te₃，粉色代表AAO。块体材料进入孔道，孔外部分保留为连续基体。去模板后柱阵列仍连在同一基体上。第7、8步将样品翻转以便显示阵列。不存在额外金属粘结层。

PPTX中的步骤标题、说明和流程箭头可编辑，立体示意模型为imagegen生成的位图。PNG可直接插入现有PPT。图示孔数、孔径、厚度、SPS工装及显微镜画面均为概念表达，没有真实尺度或实测显微结果含义。

图中未给出具体成形温度、压力和时间。用户已定制AAO，其孔径、膜厚、开孔面和铝背板状态仍待规格单确认。KOH去模板应先以同批Sb₂Te₃平片核验腐蚀及成分变化。流程图不等于经过实验验证的SOP。
