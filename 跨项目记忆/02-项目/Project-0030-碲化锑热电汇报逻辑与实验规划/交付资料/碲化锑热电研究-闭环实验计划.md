- [ ] 同批 Sb₂Te₃ 的**批次、名义成分、来源**
- [ ] 母体**组织 / 取向**
- [ ] **取样方向**（∥ / ⊥ 定义）

### 0.2 设备落实

- [ ] 结构表征：SEM（表面+截面）、XRD、成分（EDS/ICP）—— 本校何处、预约周期
- [ ] 电输运：S / σ / Hall —— 本组/本校/外测？周期与费用
- [ ] 热导：LFA 或同类 —— 同上
- [ ] **换算校验**：`P_nom(MPa) = F(N)/A(mm²)`；1 GPa=1000 MPa。⌀3 mm 需 7.07 kN、⌀10 mm 需 78.5 kN（仅单位算例，**不是**设备可达性证明）

### 0.3 模板落实

  - [ ] **Pt-BMG 铸锭能否获得**（真空电弧熔炼 + 铜模铸造）；不可得则直接外购有序 AAO
- [ ] **三维互连 AAO**：本组有无制备能力或渠道？（Part 3 硬前提；B 篇**不含**三维模板，不可外推）

### 0.4 文献参数可复现性

## 阶段 1 · 母材基线（Part 1 落地）

**目标**：产出**合格母材 B0**，作为后续所有结构化的原料与对照锚点。

**动作**：
1. 球磨制粉 → SPS 烧结 → 得到**平整致密 Sb₂Te₃ 块体 B0**。
2. 测：密度（阿基米德）、相（XRD）、成分（EDS）、S/σ（有条件补 κ）。
3. 建立 B0 的**可复用基线**（记录批次、工艺、方向、测量条件）。

**输出**：B0 的相/成分/密度/输运基线表。

**闭环回流**：若 B0 不致密或相不纯 → 回到球磨/SPS 参数调整（阶段 0 的 0.4）。

## 阶段 2 · 阵列首轮（Part 2）

**目标**：固定一个直孔 AAO + 一组条件，跑通「**入孔 → 去模板 → 留柱**」全程。

### 2.1 四组对照（同批、同取向母材）

| 样品 | 作用 | 主要比较 |
|---|---|---|
| **B0** 原始平整母材 | 加工前基线 | B1/B0：整个热压加工造成的变化 |
| **B1** 平面模热压样 | 经可比实际热压历程，无纳米成形 | 排除热压本身改变相/成分/取向 |
| **B2** 后处理平整样 | B1 再经历尽可能匹配的去模板/清洗 | B2/B1：化学处理与清洗贡献 |
| **A** 直孔阵列样 | AAO 成形并完成去模板 | A/B2：阵列相关差异，仍查 AAO 界面反应/残留 |

### 2.2 必需证据
- 表面 + 截面 **SEM**：柱径、柱高、间距、覆盖/缺柱、弯曲、裂纹
- 母体与结构层的**相/成分/取向** + 模板残留
- 去模板前留**配对截面见证样**，区分"未填充"与"后处理损失"
- 先用**同批平整小样**核验候选去模板/清洗过程的材料影响，再上阵列

### 2.3 验收线（**需事先与导师约定**）
- [ ] 能入孔
- [ ] 去模板后有柱
- [ ] 柱连着母体
- [ ] 母体不开裂

### 2.4 参数筛选顺序（起点可借 B 篇 Xiang 2022）
先固定模板/载荷/保压时间，**在已核定范围内筛温度**；选出结构完整的条件后，再单独调时间或载荷。入选条件做 **≥3 次独立制样**。

> **起点参数参考（B 篇 Xiang 2022，对象为 Ag，非 Sb₂Te₃）**：成形温度 **≈0.5Tm**（Ag 为 450 ℃）、压力 **200 MPa**、保压 **60 s**、去模板 **3 M KOH/80 ℃/≈3 h**。**代入本体系前须换算 Sb₂Te₃ 的 0.5Tm 并核实设备能力**，不可直接照搬温度与药液。

**闭环回流**：填充不足/断柱 → 回模板验收或工艺；成分/相同时变 → 回加工与后处理对照。

> **进入阶段 3 的条件**：直孔结构可独立重复成形 + 母体连接与去模板后完整性有证据 + 主要相/成分变化与后处理影响已识别。

## 阶段 3 · 多孔升级（Part 3）

**目标**：**只改一个变量**——直孔 AAO → 三维互连 AAO，其余工艺尽量不变。

### 3.1 迁移三问（是研究问题，不作为已知结果）
1. Sb₂Te₃ 能否填入**横向孔道**？
2. 去模板后**网络能否保留**？
3. 网络是否仍**连着母体**？

### 3.2 对照
三维样 **N** 与 阵列样 **A**、平整后处理样 **B2** 对比。先固定模板拓扑与成形条件；得到稳定网络后，再优先改**一种**结构参数（如连通节点间距或结构层深度）。

### 3.3 证据
- 孔/空隙尺寸、连通颈宽、结构层厚度、结构缺陷、可观察连接
- **分开定义**：二维 SEM 面积孔隙率 / 整块密度 / 表面层三维体积孔隙率
- 若"三维连通性"是核心结论 → 需多截面/序列切片或三维证据；证据不足时只报告所观察区域的连接

### 3.4 降级路线
三维互连 AAO 不可得时：**先完成阵列主线**，安排模板制备/获取；**不以普通直孔 AAO 替代三维互连模板**（否则对照不再是"纯变连通性"）。

**闭环回流**：孔道填充不完整 → 回模板通道/进料路径/单变量成形。

> **进入阶段 4 的条件**：至少有可重复的平整、阵列、网络样品 + 结构状态可定义 + 测试方式与探测对象明确 + 已识别连接过程可能破坏结构的问题。

## 阶段 4 · 应用台架（Part 4）

**目标**：平整 P / 阵列 A / 多孔 N 三组进**同一台架**，回答"表面拓扑改变了实际输出的哪一环"。

### 4.1 统一外部条件
统一主体尺寸、投影面积、取样方向、电极材料、连接工艺、夹持力、冷热边界。

### 4.2 测量顺序
1. **先测 Sb₂Te₃ 的 Seebeck 符号** → 选现成对应配对腿并保持不变；缺配对腿时先做**单材料输出台架**，结论限定于样品层面。
2. 测**实际样品/腿两端温差**、开路电压、负载 V–I / P–I、最大功率、内阻。
3. **匹配实际两端温差与平均温度**后再比较输出。

### 4.3 归因判断
- 无可靠热流与接触温差数据时 → **报告温差分配，不强行算热接触电阻**；无热输入测量时**不报转换效率**。
- 关键组做独立重复；测简短热循环后的功率/内阻漂移与结构完整性。
- 界面与几何贡献应与材料固有 ZT **分开解释**。

**闭环回流**：匹配温差后差异减小 → 回热界面；输出仍变且接触电阻也变 → 回电接触/有效输运。

## 闭环判定表（贯穿全程）

| 观察结果 | 回流到 | 可形成的结论 |
|---|---|---|
| 直孔填充不足 / 缺柱 / 断柱 | 模板验收、工艺或去模板步骤 | 本材料所试条件的成形限制 |
| 三维孔道填充不完整 | 模板通道、进料路径、单变量成形 | 一维与三维成形的差异及局限 |
| 成分 / 相 / 取向同时改变 | 加工与后处理对照、局部表征 | 拓扑与组织变化共同作用，不能单独归因 |
| 结构保留且外部同条件输出变化，匹配实际温差后差异减小 | 热界面与温差分配 | 收益可能主要来自热耦合 |
| 匹配实际温差与平均温度后输出仍变，接触电阻也变 | 电接触或有效输运 | 继续分离电接触、几何和材料贡献 |
| **无稳定收益** | 重复性、结构尺度与目标是否匹配 | **明确适用边界，不为应用演示强行解释增益** |
