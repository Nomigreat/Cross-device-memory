## 一、研究所属领域现状

### 1.1 领域定位：热电直接能量转换

本研究属于**热电材料与器件**领域。热电材料可依据塞贝克效应实现**热与电的直接相互转换**，其能量转换效率由无量纲优值 **zT = S²σT/κ** 决定（S 塞贝克系数、σ 电导率、κ 热导率、T 绝对温度）【A 篇 p.1 §Introduction；C 篇 p.1 式(1)】。

领域的现实驱动力是**废热回收**：全球超三分之二的能源消耗以热形式释放，工业每年约 **50 TWh** 以废热散失；仅回收 1% 即可减少约 **0.25 Tg/年** CO₂ 排放【C 篇 p.1 §Introduction】。近室温段（人体热、电子器件余热、低品位工业废热）的主要候选材料是 **Bi₂Te₃ 与 Sb₂Te₃**，二者因高功率因子和相对低热导，被广泛用于商用热电模块【A 篇 p.1 §Introduction】。

### 1.2 两条主流技术路线

领域内现有的提效/应用路径可归纳为**两条线**，本研究同时站在两线交汇处：

- **路线一：材料本征性能优化（提高 zT）** —— 通过缺陷工程、能带调控、纳米化等调控 S–σ–κ 的耦合关系【A 篇 p.1；C 篇 p.1】。
- **路线二：器件结构与系统设计** —— 通过结构拓扑、热管理、封装设计提升**实际输出**与**可靠性**，因为"最大化输出不只依赖材料性能，还需在系统层级精心设计器件结构与热管理"【D 篇 p.2 §Introduction】。

## 二、已有研究的进展（文献支撑）

### 2.1 制备工艺进展：球磨 + SPS 已成为块体致密化的有效途径

- **SPS 相较传统熔炼/区域提纯的优势**已被明确论证：SPS 能获得**高致密、良好键合**的结构，同时**限制晶粒长大**，通过控制晶粒尺寸、减少缺陷来改善输运性能【A 篇 p.1 §Introduction】。
- **球磨 + SPS 的具体工艺链已被验证可产出达标性能**：Bi/Sb/Te 粉经**行星式球磨（30 h / 300 rpm，Ar）** 后，用 **SPS（673 K、5–10 min、40 MPa、⌀15 mm 石墨模具、真空）** 固结，Sb₂Te₃ 取得 **zT ≈ 0.89 @523 K**、PF 峰值 3.2 mW·m⁻¹·K⁻²，且比热压样 **zT 高约 50%**【A 篇 p.1–2】。
- **工艺底座的可迁移性有旁证**：可穿戴 TEG 文献中的 Mg 基材料同样走"**球磨（550 rpm / 20 h，Ar）+ SPS（60 MPa）**"路线【D 篇 p.9–10 §Methods】，说明"球磨+SPS"是一条被反复使用的成熟工艺底座。
- **SPS 产出的材料能组装成可用模块**：8 对 p–n 偶模块在 **ΔT = 473 K 时输出约 0.37 W**【A 篇 p.2 §3；Fig.3(d)】。

### 2.2 结构成形进展：有序模板制备与"块体→阵列"成形已有完整工艺先例

- **有序 AAO 模板的低成本、大面积制备方法已建立**：以 **Pt 基块体金属玻璃（BMG）模具预压印 Al 片**（室温、50–250 MPa）→ **0.3 M 磷酸、140 V、8 min、0 ℃ 阳极氧化** → 得**长程有序 AAO 纳米模板**；若不经预压印，阳极氧化所得孔为**随机分布**【B 篇 p.2 §Results；Fig.1、Fig.2c,d】。BMG 模具因无晶界/位错而高强耐磨损（维氏 HV612，Ni 模仅 HV274），**复用 ≥50 次无可见损伤**【B 篇 p.3；Fig.S1b】。
- **超塑性纳米成形（SPNM）实现了"块体压入模板得阵列"**：金属在 **≈0.5Tm** 下压入有序 AAO 模板，材料以**蠕变填孔**形成柱阵列，**200 MPa / 60 s** 成形，**3 M KOH、80 ℃、≈3 h** 溶模板脱模；**10 min 内可得长径比 ≤10、图案面积 ≤50 mm²** 的阵列【B 篇 p.2、p.5 §2.1 Discussion；Fig.1】。
- **工艺窗口可用有限元预先圈定**：通过监测 BMG 模具内最大应力（230 nm 柱模在 250 MPa 下仅 ≈878 MPa，远低于屈服强度 1400 MPa），给出**弹性加工区间**，避免模具屈服——为"施加多大力不毁模"提供定量依据【B 篇 p.3；Fig.3h】。
- **该技术的机理源头另有经典文献支撑**：SPNM 技术承自 Liu 2017（*Nat. Commun.* 8:14910，B 篇引为文献[33]），该文阐明填孔由**晶格扩散主导蠕变**完成、纳米孔**几何约束阻塞位错**传播，长径比可拟合 `L/d = 4.65 + 1.33·t^0.36`，Ag 长径比可达 **≈2000**、最小特征 **8 nm**【Liu 2017 背景引用】。
- **多孔/三维结构对热电的价值已被证明**：三维芯–壳微晶格通过**开孔胞状拓扑**抑制"腿内热滞"，维持大热梯度并降低有效热导，在 p-Sb₂Te₃ / n-Bi₂Te₃ 上实现 **zT 0.97 / 1.09 @550 K**、比吸能 **~30 J/g**、压缩应变 **>50% 不断裂**、器件效率 **~10%**【C 篇 摘要、p.3、p.6】。

### 2.3 应用评价进展：系统级设计方法已建立

- **可穿戴 TEG 的"舒适—输出"耦合模型已建立**：夹层结构 1D 热–电–力耦合解析模型，把皮肤温度 Ts、佩戴压力 Pr 与输出 Pd/Vd 统一量化，并给出热网络（皮肤热阻 Ks、接触热阻 Kcon、模块、散热器）【D 篇 摘要、p.3；Fig.2c】。
- **性能基准可用**：**18.4 μW·cm⁻² @0.8 kPa、Ts 33 ℃**；开路电压可驱动 LED【D 篇 摘要】。

## 三、已有研究的不足（本文的切入点）

> 以下每一条都指向一个**具体的、文献未解决的缺口**，是本研究立项的直接理由。

### 不足 1：结构成形与热电性能长期"两张皮"

现有模板成形研究（如 SPNM / SPNI）**只证明结构能被做出来，但不测热电性能**。B 篇全文**无任何 S/σ/κ/PF/ZT 数据**（逐页检索 0 命中），其唯一性能演示是 SERS（增强因子 ≈10⁶）【B 篇 p.4、全文】。换言之：**"能成形"与"热电有效"之间没有被打通**。

### 不足 2：已验证的结构思路都依赖与本课题不同的工艺体系，难以直接迁移

- B 篇的 SPNM **使用万能试验机（配加热单元）而非 SPS**（全文无 "spark plasma"/"SPS" 字样），且对象是**金属**（Au/Ag/Au-Ag 合金），**不是层状化合物 Sb₂Te₃**【B 篇 p.5 §2.1 Discussion、全文】；其模板亦为**直孔六方阵列**，不含三维互连结构。
- C 篇的多孔是**DLP 3D 打印 + 热蒸发镀膜**得到的开孔骨架，与本课题"**球磨+SPS+模板反复制**"的路线**完全不同**，只能借**结构思想**而非**工艺**【C 篇 p.2 §Results】。
- D 篇材料是 **Mg 基**（Mg₃.₂Bi₁.₄₉Sb₀.₅Se₀.₀₁ / MgAg₀.₉₅Sb₀.₉₉），只可借**测试与设计方法**【D 篇 p.2 §Introduction、p.9–10】。
- **结论**：现有"结构→性能"证据分散在不同材料/工艺体系中，**尚无一条被验证的、以 Sb₂Te₃ 为基底、以球磨+SPS 为工艺的阵列表/多孔表面研究**。

### 不足 3：关键执行参数在文献中缺失，无法直接照搬

- **Sb₂Te₃ 的绝对成形温度**：B 篇给出 **≈0.5Tm** 的**通用判据**（450 ℃ 对应 Ag），但本课题体系下的绝对温度**文献未给出**【B 篇 p.2；Fig.1f 图注】。
- **Sb₂Te₃ 的去模板药液**：B 篇 **3 M KOH、80 ℃、3 h** 的脱模条件针对 Au/Ag/Au-Ag 合金，**未涵盖 Sb₂Te₃**；其可迁移性**待实验验证**【B 篇 p.2 §Results】。
- **SPS 参数不可跨体系照搬**：A 篇的 673 K/40 MPa 是**块体致密化**参数，B 篇的 200 MPa/60 s 是**万能试验机压印**参数，C 篇的 3D 打印参数、D 篇的 60 MPa 均为各自体系，**同名 MPa 不等效**。

### 不足 4："结构引入究竟让降 κ 跑赢还是拖累 PF"在 Sb₂Te₃ 上未经验证

- S–σ–κ 三者强耦合：结构引入同时带来**界面密度增加 → 声子散射降 κ**（收益）与**载流子散射 → σ 降**（代价）【A 篇 p.1；C 篇 p.1】。
- 已有工作证明"多孔有利于热电"（C 篇），但那是**别的工艺体系**的结果；在**以球磨+SPS 制备的 Sb₂Te₃ 上引入阵列/多孔后，净增益是正是负，文献无法回答**——**必须实测**。

## 四、尚待解决的问题（凝练为可检验的科学问题）

综合上述不足，本研究尚待解决的核心问题可凝练为：

| 编号 | 待解决问题 | 对应不足 |
|---|---|---|
| **Q1** | 以**球磨 + SPS**为工艺底座，能否制备出**性能达标、可重复**的 Sb₂Te₃ 母材？（材料可行性） | 不足 3 |
| **Q2** | 该母材能否**压入 AAO 模板**，形成**连接母体**的阵列/多孔结构？（结构可行性） | 不足 1、3 |

| **Q4** | 结构改变的是**材料本征贡献、几何贡献还是热耦合贡献**？（归因可解释性） | 不足 1、4 |

## 五、研究目的

### 5.1 研究动机

1. **打通"成形"与"性能"的断点**：现有模板成形研究只做结构、不测热电（不足 1），本研究把成形、表征、热电测量与器件评估**串成闭环**，让结构价值可被定量判定。
2. **把成熟工艺底座迁移到目标材料**：球磨+SPS 已是块体致密化的有效途径（2.1），本研究把它作为**统一工艺底座**，先保证母材合格（Q1），再谈结构化（Q2）——这是"最少假设"的稳健推进方式。
3. **正视而非回避净增益的不确定性**：不预设"多孔一定有益"，而是设计**平整/阵列/多孔三组同台架对比**（Q3），把"有无收益"作为**可证伪的科学结论**。
4. **面向低品位废热与可穿戴应用**：接口评价体系（D 篇）与器件效率目标（C 篇）为应用端提供判据（Q4）。

### 5.2 拟解决的核心问题

> **以「球磨 + SPS」为统一工艺底座，将 Sb₂Te₃ 从平整块体逐步结构化为表面阵列与三维多孔，验证"结构引入能否让降 κ 跑赢 PF 损失"，并回答"结构改变了实际输出的哪一环"。**

即上表 **Q1–Q4** 的联合求解。

### 5.3 研究内容（对应四部分）

| 部分 | 内容 | 回答 |
|---|---|---|
| **第一部分** | **SPS 为机制提供支撑 + Sb₂Te₃ 基底可行性**：以球磨+SPS 制备平整致密母材，建立相/成分/密度/输运基线 | **Q1** |
| **第二部分** | **阵列制备**：母材压入直孔 AAO，跑通"入孔→去模板→留柱"，四组对照（B0/B1/B2/A） | **Q2** |
| **第三部分** | **多孔结构**：只改模板拓扑（直孔→三维互连），得到多孔/互连网络 | **Q2 升级** |
| **第四部分** | **应用**：平整/阵列/多孔三组同一台架，统一外部热边界，分离材料/几何/热耦合贡献 | **Q3、Q4** |

四部分构成**"材料可行 → 结构成形 → 性能验证 → 结论回流"**的可迭代闭环。

### 5.4 预期贡献

1. **工艺层面**：给出**以 Sb₂Te₃ 为目标材料的"球磨+SPS+模板成形"工艺窗口**（成形温度、压力、保压时间与去模板条件的可复现参数），填补"该组合无直接文献"的空白。
2. **材料层面**：建立**同批 Sb₂Te₃ 母材的平整/阵列/多孔对照数据集**（相、成分、取向、密度、S/σ/κ），首次在**同一材料体系**内回答"结构引入的净增益"（Q3）。
3. **机理层面**：区分**材料本征、几何、热耦合**三类贡献（Q4），并明确"纳米孔隙在何种尺度匹配下才有益"的**适用边界**。
4. **应用层面**：以温差发电台架给出**结构—输出关系的实测判据**，为低品位废热回收与（远期）可穿戴应用提供结构设计依据。
5. **方法论层面**：形成可复用的**闭环研究范式**（每轮只变一个变量 + 每轮只交付"工艺表/原始数据/下一变量"三样），可迁移至其他热电材料的结构化研究。
