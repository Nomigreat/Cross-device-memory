## 一、汇报定位与一句话主线

**一句话主线：**

> 以「**球磨 + SPS**」为统一工艺底座，把 Sb₂Te₃ 从**平整块体 → 表面阵列 → 三维多孔**逐步结构化，验证「结构引入能否让降 κ 跑赢 PF 损失」，最终在温差发电台架上回答「结构改变了实际输出的哪一环」。

**这场汇报要回答的核心问题（不是"能不能做出结构"，而是）：**

> 阵列 / 多孔结构引入 Sb₂Te₃ 后，热导 κ 的下降能否跑赢功率因子 PF 的损失？

- **收益侧**：界面密度大增 → 宽谱声子散射降 κ_L；能量过滤 → 可能提 S。
- **代价侧**：载流子在同一批界面被散射 → σ 降；孔隙/阵列损失有效截面积。
- **关键约束**：纳米孔隙只在「声子平均自由程 ≫ 载流子平均自由程」时才有益 → 合金/晶界散射已强的体系**不预期必然增益** → 必须**实测**而非**推断**。

**这场汇报的任务边界：** 本轮只做**逻辑梳理**（主线、衔接、可行性、实验计划）；PPT 与讲稿属后续轮次。

## 二、四部分逻辑主线与衔接关系

### 2.1 总递进图

```
  Part 1 地基         Part 2 起点         Part 3 升级         Part 4 裁判
 ─────────────     ─────────────     ─────────────     ─────────────
  材料可行吗？        一维能成形吗？      三维能升级吗？      有用吗？
  SPS 撑不撑得住？    阵列 = 最小结构单元  网络 = 拓扑升级     台架 = 最终裁判
        │                 │                 │                 │
        └──── 同一批母材 + 同一工艺底座贯穿始终（控制变量）────┘
        └──────────────── 结果回流，调整工艺，重测 ────────────┘
```

### 2.2 每部分的"问题—输入—输出—衔接"

| 部分 | 回答的问题 | 输入 | 输出（可交付证据） | 衔接到下一步 |
|---|---|---|---|---|
| **Part 1** SPS 支撑 / 机制 | Sb₂Te₃ 能不能作为基底材料？球磨+SPS 能否给出性能达标、可重复的块体？ | 文献 A（同材料同工艺）+ 本组设备 | **合格母材 B0**：致密块体 + 相/成分/密度/输运基线 | 把 B0 作为后续所有结构化的**原料与对照锚点** |
| **Part 2** 阵列制备 | 块体能否压入直孔 AAO，得到连接母体的阵列？ | B0 + 直孔 AAO + SPS | **阵列样 A** + 表面/截面 SEM + 相/成分 | 阵列跑通后，**只改模板拓扑**升级 |
| **Part 3** 多孔结构 | 换成三维互连模板，能否得到多孔/互连网络？ | 阵列工艺 + 三维互连 AAO | **网络样 N** + 孔隙/连通性证据 | N 与 A、平整后处理样 B2 一起进入台架 |
| **Part 4** 应用 | 结构引入后，实际输出是收益还是代价？收益来自材料、几何还是热耦合？ | 平整 P / 阵列 A / 多孔 N 三组 | 台架输出（开路电压、V–I/P–I、最大功率、内阻） | **回流**：结果 → 调整 Part 1/2/3 的对应环节 |

### 2.3 衔接关系的三条原则

1. **同一材料来源贯穿**：四部分尽量沿用同一批 Sb₂Te₃ 母材、同主体尺寸、同取样方向，减少换体系带来的解释困难。
2. **每次只变一个变量**：Part 2→Part 3 只改**模板拓扑**（直孔→三维互连）；工艺条件改变时另配平整对照。
3. **对照逐级累加**：B0（原始母材）→ B1（同历程平面模热压）→ B2（B1 再走去模板/清洗）→ A（阵列）→ N（网络），每级只叠加一个变量。

### 2.4 四部分之间的衔接话术（讲台上怎么接）

- **Part1 → Part2**：「文献已经证明球磨+SPS 能做出性能达标的 Sb₂Te₃ 块体（zT 0.89）。**我的第一步不是重复这件事，而是把这个块体当作母材，压进直孔 AAO，拿第一个结构化样品。**」
- **Part2 → Part3**：「阵列只是一维直孔。**结构升级的关键动作只有一个——把模板从直孔换成三维互连，材料、工艺、取样方向都不动，这样结构差异才能被干净地归因。**」
- **Part3 → Part4**：「平整、阵列、多孔三组样品，**进同一台架、用同一套外部热边界**。这样输出差异才可能被拆成材料贡献、几何贡献和热耦合贡献。」
- **Part4 → 回流**：「如果台架无稳定收益，那也是**合法结论**——它告诉我们这套结构在本材料的适用边界在哪；如果有收益，就回到对应阶段优化结构尺度。」

## 三、闭环论证结构（本方案的核心）

### 3.1 为什么必须是闭环，而不是"四部分讲完"

四部分若只做线性递进，汇报会停在"我把四件事讲清楚了"。**真正的研究逻辑要求：每一环的输出既是下一环的输入，又要能回流修正上一环。** 因此本方案把四部分组织为一个**可迭代闭环**。

### 3.2 四级闭环（由内到外）

| 层级 | 闭环内容 | 收敛条件 | 产物 |
|---|---|---|---|
| **L1 单轮小闭环** | 母材 → 阵列成形 → 结构表征 → 调整工艺 → 再成形 | 结构可稳定重复 | 阵列工艺窗口 |
| **L2 阶段闭环** | 阵列稳定 → 上三维模板 → 网络成形 → 回到阵列工艺修正 | 网络保留且连接母体 | 多孔/网络工艺 |
| **L3 任务闭环** | 平整 P / 阵列 A / 多孔 N → 同一台架 → 输出对比 → 分离贡献 | 输出差异可归因 | 结构—性能关系结论 |
| **L4 研究闭环** | 结论 → 结构尺度/工艺优化 → 回 Part 2/3 重制 | 最优结构参数 | 可发表的核心图 |

### 3.3 闭环条件（"什么算闭合"）

一个阶段被判为**闭合**，必须同时满足：

1. **结构可重复**：入选工艺至少 3 次独立制样，片间重复性与片内均匀性有数据。
2. **相/成分/取向可解释**：母体与结构层的相、成分、取向有证据（XRD/EDS 等，注意探测体积匹配）。
3. **测式与探测对象明确**：S、σ、κ 对应**同一对象、同一方向、同一温区**才可算 ZT；薄表面层不能凭整块微小变化直接宣称自身 ZT 提升。
4. **已识别连接破坏问题**：电极连接前后检查结构，避免比较对象已被破坏。

### 3.4 回流路径表（每种观察 → 回到哪里 → 可形成什么结论）

| 观察结果 | 回流到 | 可形成的结论 |
|---|---|---|
| 直孔填充不足 / 缺柱 / 断柱 | 模板验收、工艺或去模板步骤 | 本材料在所试条件下的成形限制 |
| 三维孔道填充不完整 | 模板通道、进料路径、单变量成形 | 一维与三维成形的差异及局限 |
| 成分 / 相 / 取向同时改变 | 加工与后处理对照、局部表征 | 拓扑与组织变化共同作用，**不能单独归因** |
| 结构保留且同条件下输出变化、匹配实际温差后差异减小 | 热界面与温差分配 | 收益可能主要来自热耦合 |
| 匹配实际温差与平均温度后输出仍变、接触电阻也变 | 电接触或有效输运 | 继续分离电接触、几何、材料贡献 |
| **无稳定收益** | 重复性、结构尺度与目标是否匹配 | **明确适用边界，不为应用演示强行解释增益** |

> **关键立场**：**"无稳定收益"是本方案的合法闭环结论之一**，不是失败。讲台上必须主动讲这一点，它体现研究的可证伪性。

### 3.5 闭环的"每轮只交付三样"

每完成一轮，只交付：
1. 有出处的工艺 / 阅读表；
2. 可比较的原始数据与结构证据；
3. 下一轮**只改变哪一项**及原因。

### 总评

- **路线逻辑自洽**：四部分递进清晰、与已积累的文献包（10 篇主线 + 辅助）完全咬合。
- **最大不确定性不在逻辑上**，而在两个**资源/实验问题**：

## 六、证据纪律与待核验清单（防追问）

### 六条证据纪律

1. **只有 Part 1 是同体系证据**，Part 2/3/4 均为跨材料/跨工艺借鉴 → 逐条标注"可迁移项 / 不可越界项"。
2. **同名 MPa/GPa 与"控制温度"不等效**：压机与 SPS 加载路径、通电、升温速率均不同。
3. **不跨样品/方向拼数据**：S、σ、κ 必须对应同一对象、同一方向、同一温区才可算 ZT。
4. **原文未给的不推算**：Sb₂Te₃ 绝对成形温度、去模板药液，一律写"原文未给出/待核验"。
5. **洛伦兹数取法要写进方法**：κ_L 与 ZT 对 L 的取值极敏感（简并极限误差可达 ~40%）。
6. **"无稳定收益"是合法结论**，不为演示强行解释增益。
