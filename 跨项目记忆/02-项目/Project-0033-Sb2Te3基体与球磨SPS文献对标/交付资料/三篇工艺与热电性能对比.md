# 三篇 Sb₂Te₃ 相关论文：球磨、SPS 与热电性能对比

阅读日期：2026-10-10。依据用户提供的三份完整正文 PDF（共21页）。正文主图23幅、主表5张已逐项检查；未提供补充材料（SI）。页码均指 PDF 文件的页序号。

**结论：2022篇适合作为 Sb₂Te₃ 基掺杂材料的基础工艺参考；2023篇覆盖从材料到分段热电腿实测的完整链条；2014篇的元素粉末直接机械合金化路线最简，但其报告的高 ZT 受测量方向混用影响，不能直接作为优于前两篇的依据。**

A的10⁻⁵ torr约为1.33×10⁻³ Pa（单位换算），与B的约10⁻³ Pa处于相同数量级。它们都是熔炼封管的真空，不能自动当成球磨或SPS气氛。

三条流程：

**A：** 元素配料 → 石英管真空封装 → 800 ℃/10 h熔炼 → SPEX球磨2 h → φ12.7 mm石墨模具 → 真空SPS 400 ℃/80 MPa/5 min → 块体表征。

**B：** 元素配料 → 石英管真空封装 → 800 ℃/10 h熔炼 → 炉冷 → SPEX高能球磨（时长未给）→ SPS 400 ℃/80 MPa/5 min → 多尺度结构与热电表征 → 与低温Bi₀.₄Sb₁.₆Te₃.₀₁组合成分段腿。

**C：** 元素粉末配料 → Ar手套箱装料、球料比3∶1 → SPEX机械合金化（最佳5 h；2 h已有单相）→ SPS 450 ℃/20 MPa/4 min → 热电表征。SPS气氛需补核。

A与B的SPS温度、压力、保温相同，主要差别在成分与结构设计。C的烧结温度高约50 ℃，压力为A/B的四分之一，且省去10 h熔炼，但改变的不只是工艺，材料成分也不同。三篇均不能直接用行星球磨的“300 rpm”代替SPEX设备条件。

### 必须保留的三个数据边界

**① C文的“PF”多了T。** PDF p4直接写PF=(S²T)/ρₑ，Fig.8轴单位为W·m⁻¹·K⁻¹。标准PF为S²/ρₑ，单位W·m⁻¹·K⁻²。因此原文2 h样品“约1 W·m⁻¹·K⁻¹@360 K”对应标准PF约2.78 mW·m⁻¹·K⁻²，不能当成1 W·m⁻¹·K⁻²。5 h样品的换算使用其自己的图读≈0.90，而不是2 h样品的≈1。其ZT公式本身含T，不能因为Fig.8命名问题就自动认定ZT又多乘了一次T。

**② C文的ZT使用了两个方向。** PDF p5明确：S和ρₑ沿垂直SPS压力方向测量；热导率/热扩散率沿平行压力方向测量。作者承认各向异性可能导致报告的高ZT，并表示需要完整性能测试消除影响。作者估计真实ZT约1或以上，这仍是估计，不能替换成已经实测的“修正ZT”。故表中1.2–1.3应标记为**混合测量方向计算值**。

**③ B文多个最优指标对应不同成分。** Cu0.035样品Sb₁.₈₁₅In₀.₁₅Cu₀.₀₃₅Te₂.₉₈的κL最低达到**0.44 W·m⁻¹·K⁻¹，523 K以上**；正文结论还将PF **16.43 μW·cm⁻¹·K⁻²@573 K**对应到Cu0.035样品。最高ZT **1.06@623 K**则属于Cu0.03。不能把0.44、16.43和1.06无条件列成同一样品的性能。

B还有一处需保留的图文核对点：p3文字称Cu0.03的PF为15.2 μW·cm⁻¹·K⁻²@673 K，而Fig.6c的Cu0.03曲线在673 K读数约14.4，在623 K约15.1；Cu0.035在673 K约15.2。本表采用与最高ZT温度对应的**623 K图读值**，不静默改写作者的673 K表述。原始数据/SI可进一步核对这处温度或成分对应。

## 6. 对你的用途的判断

- **准备Sb₂Te₃基基础实验流程：优先A。** 正文明确给出了熔炼、球磨时长、模具、SPS温度/压力/保温及测量方向。仍需补球料比、球/罐材质、装料量和升温程序，不能称为完整可直接执行的设备SOP。
- **做工艺—结构—性能—发电的文献汇报：优先B。** Te缺失→孪晶，In调整→带隙/平均ZT，Cu调整→电输运/多尺度结构，最后实际制作分段腿，论证链更完整。其球磨时长和同方向测量说明仍是正文空缺。
- **比较“球磨多久合适”：C最有直接时间对照。** 2 h已成相，5 h的报告ZT最高，继续延长到20/30 h没有持续改善。这个结论只针对该设备和Bi₀.₄Sb₁.₆Te₃，不可直接外推到纯Sb₂Te₃或行星球磨。
- **确定热电测试方案：记录方向比只抄峰值更重要。** 应为每个样品标出电学/热学相对于SPS轴的方向，并比较同一方向下的S、σ和κ。

[分析] B呈现室温孔洞/多尺度结构，但并非通过受控造孔设计建立孔隙率—性能关系的论文。把它用于多孔热电研究时，可借鉴结构表征和输运解释，不能据此认定增加孔隙必然提高ZT。
